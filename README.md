# CS2024-html-assignment
HTML assignment for CS2024: a 3-page website for **Ember & Oak**, a fictional café for students.

Open `index.html` in a browser (desktop).

| Page | File |
|---|---|
| Homepage | `index.html` |
| Subpage (Menu) | `menu.html` |
| Content page (Our story) | `story.html` |

- Styles: `css/style.css` (plain CSS, no frameworks)
- Favicon: `images/favicon.svg` (+ `favicon.png` fallback)
- Photos: Unsplash, credits in `images/CREDITS.md`
- Planning document: `planning/Ember-and-Oak-planning.docx` (wireframe/sitemap source: `planning/diagrams.html`)
